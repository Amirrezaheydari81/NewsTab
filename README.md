# نیوز تب

![cover](cover.jpg)

افزونه کروم صفحه تب جدید را با فیدهای RSS دلخواه شما به یک مرکز خبری شخصی‌سازی‌شده تبدیل می‌کند.

![Manifest V3](https://img.shields.io/badge/Manifest-V3-green)
![License MIT](https://img.shields.io/badge/License-MIT-lightgrey)
![Version](https://img.shields.io/badge/Version-1.2.0.0-purple)

## ویژگی‌ها

- **فیدهای RSS نامحدود** — هر تعداد فید دلخواه اضافه و مدیریت کنید
- **تا ۱۰ خبر در هر فید** — تیترها از جدید به قدیم، با تاریخ انتشار جمع‌وجور کنار هر خبر
- **مرتب‌سازی بر اساس تازه‌ترین سایت** — کارت فیدهایی که جدیدترین خبر را دارند بالاتر می‌آید
- **ترجمه خودکار فارسی** — تیترها را به فارسی ترجمه می‌کند
- **حالت کم‌مصرف** — برای سیستم‌های ضعیف‌تر با کاهش همزمانی، تعداد آیتم و فاصله به‌روزرسانی
- **جستجو در تیترها** — فیلتر سریع بین همه فیدها
- **کاهش فشار سیستم** — بدون فچ خودکار در باز شدن تب و با کش حافظه
- **گروه‌بندی فیدها** — فیدهای هم‌نام را در گروه‌های جدا ببینید
- **نقل‌قول انگیزشی** — نقل‌قول روزانه با ترجمه فارسی
- **قیمت‌های لحظه‌ای** — نمایش قیمت طلا و دلار با ویجت tgju
- **منوی برچسب‌دار** — دسترسی سریع به تنظیمات با طراحی شیشه‌ای
- **پاکسازی کش** — دکمه اضطراری برای پاکسازی کامل کش
- **فونت وزیرمتن محلی** — از پوشه `fonts/` لود می‌شود، بدون CDN
- **رابط کاربری RTL** — طراحی شیشه‌ای تیره با Tailwind CSS 4

## نصب

### روش ۱: نصب مستقیم (Developer Mode)

1. فایل‌های پروژه را کلون یا دانلود کنید
2. در کروم به آدرس `chrome://extensions/` بروید
3. گزینه **Developer mode** را فعال کنید
4. روی **Load unpacked** کلیک کنید و پوشه اصلی پروژه را انتخاب کنید

### روش ۲: بیلد برای انتشار

```bash
npm install
npm run build
```

فایل‌های تولیدشده در پوشه `dist/` آماده‌ی بارگذاری در مرورگر هستند.


## توسعه

### پیش‌نیازها

- Node.js >= 18
- npm

### اسکریپت‌ها

| دستور | توضیحات |
|--------|---------|
| `npm run css` | کامپایل Tailwind از `src/input.css` به `style.css` |
| `npm run css:watch` | تماشای تغییرات CSS در حال توسعه |
| `npm run build` | کامپایل CSS، minify جاوااسکریپت و کپی به `dist/` |
| `npm test` | اجرای تست‌های واحد (در صورت وجود `test.js`) |

### افزودن فید جدید

از منو، گزینه **تنظیمات فید** را باز کنید و فید جدید اضافه، حذف یا جابه‌جا کنید.
